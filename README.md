Online Shop Java

A Java-based Online Shopping System developed using Object-Oriented Programming (OOP) principles.

About the Project

This project is an online shopping system initially developed as a console-based Java application. It will be expanded into a full-stack e-commerce platform.

Current Features

- Product management
- Customer management
- Order processing
- Order items
- Payment methods
- Discount strategies
- Order status management

Technologies

- Java
- Object-Oriented Programming
- IntelliJ IDEA
- GitHub

Future Development

- Spring Boot Backend
- MySQL Database
- RESTful APIs
- User Authentication
- Shopping Cart
- Web-based User Interface
- Admin Dashboard

Project Status

Currently under development.
